Política de privacidad de Esputifai

Última actualización: 10 de noviembre de 2026

Esputifai es una app personal de Android para escuchar música de YouTube Music. No tiene servidor propio: no recoge, no guarda y no vende datos de nadie.

Qué datos usa

Tus listas de reproducción, tu Albumteca y el número de veces que has escuchado cada canción. Se guardan en tu propio dispositivo.

Google Drive

Si inicias sesión con Google, la app usa el permiso drive.appdata para guardar esos mismos datos en una carpeta oculta y privada de la app dentro de tu Google Drive, y así tenerlos iguales en todos tus dispositivos. Con ese permiso la app no puede ver ni tocar ningún otro archivo de tu Drive. Nadie más, tampoco quien desarrolla la app, tiene acceso a esa carpeta.

Puedes borrarla cuando quieras desde Google Drive → Configuración → Gestionar aplicaciones → Esputifai → Eliminar datos de aplicación ocultos, y retirar el acceso en myaccount.google.com/permissions.

El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

YouTube

Para buscar y reproducir, la app se conecta directamente a YouTube, que aplica su propia política de privacidad.
